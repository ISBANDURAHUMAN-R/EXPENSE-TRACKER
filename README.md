# Expense Tracker
A Python-based Expense Tracker that helps users manage daily expenses and monitor spending habits.

## Features
- Add expenses
- View all expenses
- Calculate total spending
- Category-wise summary
- CSV data storage

## Technologies Used
- Python
- CSV File Handling
